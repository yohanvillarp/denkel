🌿 Core Architectural Clarifications & Decoupling

  • Direct vs. Subtask Time Breakdown: Projects report total hours while explicitly breaking down direct effort (e.g. 2h) versus subtask contributions (e.g. 7h = 9h total), preventing double-counting and data loss.
  • Provisional Branches: Unrelated tasks sprout directly from the trunk as a provisional primary branch without force-inventing unnecessary categories.
  • Active Timer Crash Resilience: Active session state (running/paused, start timestamp, active elapsed duration) persists across browser refreshes and tab reloads.
  • Decoupled Status & Time: A task in "Pending" can have logged exploratory hours, rendering as an unopened bud with earned branch thickness.
  • Categories vs. Tasks: Structural containers (e.g., "University") organize hierarchy without timers or completion buttons. Actionable tasks retain full tracking.
  • Continuous Elapsed Timer: Circular indicator animates smooth elapsed time, avoiding arbitrary countdown percentages or artificial deadlines.
  • Adaptive Zoom (LOD): Overview zoom collapses subtasks into clean branch tips to prevent text collision; close-up zoom reveals full titles and twigs.

🖥️ Screen Surfaces & Layout

The Living Canvas & Adaptive Level of Detail (LOD)

Clean, warm-white screen where the botanical tree takes center stage with adaptive detail to prevent clutter at scale.

Overview Zoom (LOD 1)

Major categories and primary projects visible; minor twigs collapse into clean tips without text overlap.

Close-up Zoom (LOD 2)

Subtask titles, state markers, and leaf clusters smoothly fade in when focusing on a branch cluster.

Provisional Branches

Unrelated tasks sprout directly from the trunk without force-inventing artificial single-item categories.

Task Details Drawer (Slide-Over)

Slides in from the right when an actionable task is clicked. Transparently displays direct effort and subtask contributions.

  • Displays Task Title, Hierarchy Path (e.g. University > Thesis > Matrix), and current status badge.
  • Direct vs. Subtask Breakdown: Clearly separates hours logged directly on the node from hours contributed by child tasks (e.g. Total: 9h — Direct: 2h, Subtasks: 7h).
  • Session History Log: Displays past individual sessions (e.g., Oct 10: 40m, Oct 11: 1h) and the sum total.
  • Two primary action triggers: Start Timer (Focus Mode) or Log Time Manually (inline form).
  • Status toggle to mark task as completed (sprouts leaf clusters without altering logged time).

Distraction-Free Focus Mode (Crash Resilient)

Inspired by the clean Stitch design. The tree completely fades away, centering the user's mind entirely on the work at hand.

  • Serene, slightly greenish-white background with no visual noise.
  • Task title cleanly anchored at the top.
  • Large central timer with a continuous elapsed-time sweep animation (no artificial progress percentage).
  • Crash/Reload Resilience: Actively running or paused timer state is automatically restored if the page is refreshed or tab closed.
  • Only two essential controls: Pause / Resume and Finish.

Floating Semantic Search

Invoked via top search icon or shortcut (`/` or `Ctrl+K`) without leaving the living canvas.

  • Accepts exact task names or approximate queries (e.g. "unfinished thesis task").
  • Result items show task name, category path, and status badge.
  • Selecting a result triggers smart camera navigation: zooms out slightly to orient, glides to target branch, highlights it, and slides open details drawer.
🌿 The 3 Botanical Lifecycle States (Decoupled from Time)

Lifecycle state and accumulated hours are 100% independent. A task can have recorded hours in any state:

Pending (Bud)

Unopened Bud

Rendered as a small rounded amber bud. Indicates pending status (can have accumulated exploratory time and earned thickness while remaining pending).

In Progress

Growing Branch

Active branch with thickness scaling with logged time up to a defined ceiling to preserve layout aesthetics.

Completed

Developed with Leaves

Sprouts vibrant green leaf clusters along the branch tip. Retains full branch thickness and earned effort.

🛡️ Consequential States & "What If?" Matrix
Empty State & Germination

Brand new user sees a small seedling trunk with "Plant your first task below...". First task triggers a brief germination animation into a trunk and branch. Zero fictional dummy tasks.

Semantic Ambiguity

If the AI detects multiple potential parent candidates (e.g. "Review project"), it displays an inline clarification question in the bar before moving or modifying branches.

Empty or Gibberish Input

Empty Enter displays subtle "Please enter a task". Gibberish asks for clarification while preserving the typed text in place for easy editing.

Crash / Reload Resilience

Refreshing the page during a running or paused focus session seamlessly restores the timer state with zero lost time.

📋 Verifiable Acceptance Criteria
  • Categories act as organizational groupings without timers or completion buttons.
  • Actionable tasks support live timer, manual entry, session history, and completion toggles.
  • Parent nodes with subtasks clearly display both Direct Node Hours and Subtask Contributed Hours (e.g. 9h total = 2h direct + 7h subtasks).
  • Entering an unrelated task sprouts a provisional primary branch from the trunk without force-inventing unnecessary categories.
  • Refreshing or closing/reopening the page while a timer is active seamlessly recovers the session state (running or paused) without data loss.
  • A task can hold recorded time while in "Pending" status, rendering as an unopened bud with earned thickness.
  • Focus Mode timer circular indicator animates elapsed time without an artificial percentage limit.
  • Details drawer logs discrete session entries (date + duration) and shows the sum total.
  • Adaptive LOD prevents text collisions at overview zoom and reveals labels on close-up zoom.
  • All tasks, categories, session logs, and active timer state persist across browser refreshes via the storage abstraction.
