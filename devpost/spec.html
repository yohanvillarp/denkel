Secure local proxy pipeline, off-screen D3 coordinate solver, Canvas 2D organic renderer, and storage abstraction:

🧩 Architectural Responsibilities & Technical Blueprints

Decoupled 3-Part Visualization Architecture

Cleanly decoupled responsibilities: layout calculation never touches pixels, and the renderer never calculates topology.

D3TreeLayoutEngine

Builds a d3.hierarchy and executes d3.tree(). Guarantees zero branch collisions across arbitrary depths. Outputs target coordinates { targetX, targetY }.

CameraController

Handles viewport math: (panX, panY, zoom). Translates mouse clicks to world coordinates for hit-testing. Smoothly eases camera during search and node focus.

TreeRenderer

Draws organic cubic Bézier curves on Canvas 2D. Smoothly morphs nodes from current to target coordinates. Applies bounded bark thickness and LOD label management.

Secure Local Proxy & Strict Validation Guard

API keys remain strictly server-side in .env; client validation ensures zero corrupted graph relationships.

Local Server Proxy (server/api.ts)

Reads GEMINI_API_KEY securely from local .env. Proxies calls to Gemini Flash-Lite (gemini-3.5-flash-lite) with structured JSON schemas.

Conservative Fallback

When offline or lacking an API key, registers tasks as provisional branches directly off the trunk—avoiding crude or inaccurate guesses.

TreeIntegrityGuard

Validates proposed tree operations: verifies acyclic graph rules (no cycles), confirms parent IDs exist, and strictly ensures zero data or time loss.

Provisional Branches

Unrelated tasks sprout without force-creating single-item parent categories, awaiting future pattern recognition.

Data Abstraction & Crash Resilience

State sits behind IStorageAdapter, decoupled from browser storage APIs.

  • Active Session Recovery: Active timer state (task ID, start timestamp, running/paused status, accumulated duration) is persisted every 5 seconds. Refreshing or reopening the tab restores the session with zero lost time.
  • Effort Breakdown: Tasks store individual session history logs (e.g., Oct 10: 40m, Oct 11: 60m = 100m total).
  • Zero Double-Counting: Parent projects clearly distinguish Direct Node Hours from Subtask Contributed Hours.
  • Future Drop-in: Cloud databases (e.g., PostgreSQL / Neon) can be swapped in without modifying any React or Canvas code.

📦 TypeScript Domain Models 
export type TaskStatus = 'pending' | 'in_progress' | 'completed';
export type NodeType = 'category' | 'project' | 'task';

export interface SessionLog {
  id: string;
  startTime: string; // ISO date
  durationMinutes: number;
  note?: string;
}

export interface TaskNode {
  id: string;
  title: string;
  type: NodeType; // 'category' (structural only) | 'project' | 'task'
  parentId: string | null;
  status: TaskStatus; // independent of hours
  directMinutes: number; // minutes logged directly to this node
  sessionHistory: SessionLog[];
  isProvisional?: boolean;
  createdAt: string;
  updatedAt: string;
}

export interface ActiveTimerState {
  taskId: string;
  startTime: number; // Unix timestamp
  accumulatedSeconds: number;
  isPaused: boolean;
}
