Denkel — App Map

A living, organic botanical task manager where effort becomes tangible growth. Tasks are branches, subtasks are leaves, and recorded hours nurture and thicken the tree.

1. Overview & Core Architecture

Denkel turns abstract to-do lists into an evolving botanical tree rendered on an interactive HTML5 canvas. The architecture is cleanly divided into four reactive layers:

  • Natural Language Input: Submits free-form tasks, triggering intelligent categorization or graceful local fallbacks.
  • Integrity Guard & Engine: Guarantees graph acyclicity, preserves accumulated time, and calculates natural collision-free coordinates via d3-hierarchy.
  • Organic Canvas Renderer: Translates coordinates into curved botanical branches, tapered trunks, effort-thickened stems, and level-of-detail tags.
  • Guided Camera & Drawer: Glides the viewport smoothly across the canvas to highlight branches while synchronizing with the details drawer.

2. Reference Code Route

To follow a task from submission to visual life on canvas, follow these three stable code anchors:

Stop 1: Task Ingestion & AI Routing
src/components/TaskInputBar.tsx → handleSubmit()

Captures the user prompt, sends it to the AI orchestrator or local fallback provider, and invokes addTask() with parent references.

Stop 2: Acyclic Graph Mutation & Layout Engine
src/tree/D3TreeLayoutEngine.ts → calculateLayout()

Translates parent-child relationships into natural branch angles and radial lengths. Resolves label collisions dynamically and staggers branch emergence.

Stop 3: Effort-Thickened Branch Rendering & Camera Flight
src/tree/TreeRenderer.ts → renderBranches() / renderNodes()

Scales branch thickness logarithmically based on accumulated minutes: branchWidth = baseThickness + Math.min(2.5, Math.log1p(node.totalMinutes) * 0.45). Differentiates categories from tasks with radiant beacons.

4. A Practice to Reuse

Visible Canvas Projection Geometry: When building applications with persistent side drawers (e.g. inspector panels, task drawers), avoid brittle hardcoded horizontal pixel offsets to center camera targets.

Instead, derive the target screen point from the actual visible viewport: targetScreenX = (screenWidth - drawerWidth) / 2, and compute the camera pan using the projection invariant: 

panX = targetScreenX - targetWorldX * zoom;

This single invariant guarantees pixel-perfect centering across all screen sizes, device pixel ratios, drawer states, and zoom scales.
