Denkel

A living tree task manager using AI to semantically structure tasks and visualize accumulated effort over time.

scope status: approved
🛡️
Architectural Constraints & Data Integrity Guard:

1. AI Strict Constraints: Zero phantom tasks, no duplicate nodes, stable IDs during re-parenting, zero data/time loss, and strict acyclic graph integrity.
2. Storage Abstraction: Core state sits behind a pluggable storage interface (LocalStorage adapter for PoC) so cloud backends can drop in seamlessly later.
3. Deliberate Interaction: Camera navigates to task details first; timer never auto-starts, and manual time logging is a first-class feature alongside the live timer.

✦ The Unique Kernel

Instead of tasks vanishing into completed checklists that undervalue human effort, Denkel visualizes work as an organic living tree where branches grow and develop based on accumulated time, while AI dynamically organizes and reorganizes the hierarchy from natural language input.

👤 Who It's For & Why It Matters

Primary Persona: A university student managing simultaneous responsibilities (thesis, coursework, projects, chores) overwhelmed by manual organizing.

"I want users to open the app and say, 'Wow, I spent so much time on this, and I actually did it!'"

★ What "Working" Looks Like

A 60–90 second screen recording demonstrates:

  • Natural Input: Enter task & watch AI link under parent while preserving existing IDs and data.
  • Smooth Camera: Seamless glide directly to the target node.
  • Details First: Panel opens showing task info with two options: live timer or manual entry.
  • Effort Logged: User runs live timer or inputs hours; branch visually expands growth.
  • Instant Search: Search query smoothly navigates camera to the matching branch.
